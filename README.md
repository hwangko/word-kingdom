# 🏰 단어왕국 땅따먹기 (온라인 버전)

학생들이 각자 태블릿으로 접속해서 영어 단어를 맞히고, 우리 모둠 땅을 넓히거나 다른 모둠 땅을 빼앗는 게임이에요.
서버를 직접 만들 필요 없이 **GitHub Pages(또는 Cloudflare Pages) + Firebase 무료 요금제**로 운영할 수 있어요.

## 파일 구성
| 파일 | 설명 |
|---|---|
| `index.html` | 게임 전체 (학생 화면 + 선생님 화면) |
| `firebase-config.js` | 내 Firebase 설정값을 붙여넣는 파일 (**꼭 수정해야 해요**) |
| `database.rules.json` | Firebase 데이터베이스 규칙 (콘솔에 붙여넣기) |

## 1단계. Firebase 준비 (약 10분, 한 번만)
1. https://console.firebase.google.com 접속 → 구글 계정으로 로그인 → **프로젝트 추가** (이름 예: `word-kingdom`, Google 애널리틱스는 꺼도 돼요).
2. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기**
   - 위치: `asia-southeast1 (싱가포르)` 추천
   - 보안 규칙: 일단 **잠금 모드**로 시작해도 괜찮아요 (바로 다음에 규칙을 바꿔요).
3. **규칙** 탭에서 `database.rules.json` 의 내용을 전부 붙여넣고 **게시**.
4. 톱니바퀴 **프로젝트 설정 → 일반 → 내 앱 → 웹(</>) 앱 추가** → 앱 닉네임 입력 → 나오는 `firebaseConfig` 값을 복사.
5. `firebase-config.js` 를 열어 `여기에_붙여넣기` 자리에 값을 넣어요. `databaseURL` 도 꼭 있어야 해요. (Realtime Database 화면 맨 위에 주소가 보여요.)

## 2단계. 인터넷에 올리기 (git)
### GitHub Pages
1. GitHub에서 새 저장소(repository) 만들기 (공개 Public).
2. `index.html`, `firebase-config.js`, `database.rules.json`, `README.md` 를 올리기 (Add file → Upload files).
3. **Settings → Pages → Branch: main / (root) → Save**
4. 1~2분 뒤 `https://내아이디.github.io/저장소이름/` 주소가 생겨요. 이 주소가 학생들이 접속할 주소예요.

### (또는) Cloudflare Pages
Cloudflare 대시보드 → Workers & Pages → Pages → **직접 업로드**로 폴더를 끌어다 놓으면 `○○○.pages.dev` 주소가 생겨요.

> Firebase 웹앱 설정값(apiKey 등)은 공개되어도 괜찮은 값이에요. 대신 데이터 보호는 데이터베이스 규칙이 담당해요.

## 3단계. 사용하기
### 진행 방식 두 가지 (방 만들 때 선택)
- **상시 진행 (기본)**: 방을 만들면 바로 게임이 시작돼요. 선생님이 접속하지 않아도 학생들이 방 코드로 **아무 때나** 들어와 계속 이어서 할 수 있어요. 마감일을 정하면 그 날 밤 12시에 자동으로 끝나고, 비우면 선생님이 종료할 때까지 계속돼요.
- **수업용**: 선생님이 **게임 시작/일시정지/종료** 버튼으로 진행하고, 게임 시간(분)을 정해 자동 종료할 수 있어요.

선생님은 나중에 **이어하기**(방 코드 + 비밀번호)로 들어와 순위를 보거나, 일시정지·종료·지도 초기화를 할 수 있어요.

### 수업에서 쓰는 순서
1. 선생님: 주소 접속 → **새 방 만들기** → 모둠 수/지도 크기/단어/진행 방식을 정하고 방 만들기.
2. 화면에 크게 나오는 **방 코드(4글자)** 또는 링크를 학생들에게 알려 주세요. (링크로 들어오면 코드가 자동 입력돼요.)
3. 학생: 코드 + 별명 입력 → 모둠 선택 → 대기. (시작 전에는 "모둠 바꾸기" 가능)
4. (수업용일 때) 선생님: **게임 시작** → 학생들은 노란 점선 칸(내 땅과 붙은 칸)을 눌러 문제를 풀고 땅을 차지해요.
5. 종료 시간이 되면 자동으로 끝나고 결과(모둠 순위 + 활약한 친구들)가 나와요.

### 게임 규칙
- 모둠마다 **근거지(2×2, 🏰)** 가 있고, 근거지는 **빼앗을 수 없어요**.
- 내 모둠 땅과 **상하좌우로 붙어 있는 칸**만 도전할 수 있어요. 다른 모둠 땅도 도전 가능!
- 땅 1칸을 차지하려면 **객관식 2문제 → 주관식 1문제**를 차례로 모두 맞혀야 해요. 하나라도 틀리거나 시간이 지나면 처음부터 다시 도전해요(몇 초 쉬었다가). 시간 제한은 문제 1개당이에요.
- 주관식은 시간이 지나면 힌트가 나와요. 제한 시간의 30%가 지나면 글자 1개(예: `v _ _ _ _`), 60%가 지나면 2개를 보여줘요.
- 문제는 아직 못 맞힌 단어가 더 자주 나와요.
- 학생 화면 아래에 **단어 마스터율**(내가 한 번이라도 맞힌 단어 수 / 선생님이 등록한 전체 단어 수, %)과 정답률이 표시돼요. 선생님 화면에는 학생별 마스터율, 학급 평균, 많이 틀린 단어가 나와요.
- **포위**: 우리 땅으로 빈 칸/다른 모둠 땅을 빙 둘러싸면 안쪽이 한 번에 우리 땅! (지도 가장자리에 닿은 칸, 다른 모둠 근거지와 이어진 칸은 포위로 치지 않아요.)

### 진행 상황 저장
모든 상태(지도, 학생 기록, 설정)는 Firebase에 실시간 저장돼요. 브라우저를 닫아도, 다음 날에도 **선생님 첫 화면 → 이어하기**(방 코드 + 비밀번호)로 그대로 이어서 할 수 있어요. 같은 태블릿으로 다시 접속한 학생은 자동으로 기존 기록을 이어받아요.

## 주의사항
- **수업용 간이 보안**이에요. 방 코드를 아는 사람은 데이터를 바꿀 수 있고, 선생님 비밀번호도 간이 잠금이에요. 학생에게 방 코드는 수업 때만 알려 주세요.
- 정답이 단어 목록과 함께 학생 기기로 전달돼서, 개발자 도구를 열면 정답을 볼 수 있어요. 일반적인 수업에는 문제가 되지 않지만 알고 계세요.
- 개인정보 보호를 위해 학생에게 실명 대신 **별명이나 번호**를 쓰게 하는 것을 권장해요. 학기가 끝나면 **방 삭제**로 기록을 지워 주세요.
- Firebase 무료(Spark) 요금제로 한 학급 수업은 충분해요. (동시 접속 약 100명 수준)
- 학교 네트워크에서 Firebase(`firebasedatabase.app`)나 `gstatic.com` 이 막혀 있으면 접속이 안 될 수 있어요. 수업 전에 한 번 테스트해 보세요.

## 방 삭제하기
- **첫 화면**: 내 방 목록의 **삭제** 버튼, 또는 방 코드(+비밀번호)를 입력하고 **방 삭제** 버튼. 비밀번호를 설정한 방은 비밀번호를 확인해요.
- **방 안**: 선생님으로 들어가 오른쪽 패널 맨 아래 **관리 → 방 삭제**.
- 삭제하면 복구할 수 없어요. 지도만 새로 시작하려면 삭제 대신 **지도 초기화**를 쓰세요.
